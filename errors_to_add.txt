• E0701: Ambiguous Statement Disambiguated as Variable Declaration
	• Context: The classic C++ Most Vexing Parse. The code Time Keeper(Timer()); could be a function call or a variable declaration. Your recursive descent parser uses tentative parsing, picks one, and warns the developer exactly how it resolved the ambiguity.
• E0702: Missing 'typename' or 'template' Keyword in Dependent Scope
	• Context: The parser hits T::InternalType* ptr;. Without a hint, it doesn't know if InternalType is a static variable being multiplied or a type being pointed to. It flags that it assumed a value but likely intended a type.
• E0703: Tentative Parse Rollback Limit Exceeded
	• Context: A safety valve for your handwritten parser. If a massive, malformed expression forces the parser to use lookahead/speculative parsing down too many branches without hitting a synchronizing token (like a semicolon or brace), it kills the branch to prevent compiler stack overflow.

• ~~T0002: Return With No Value in a Value-Returning Function~~  ✔ DONE
	• Emits: `return with no value in function returning 'i32'`
	• Help: `write `return <expr>;` or change the function's return type to void`
	• Context: bare `return ;` inside a non-void function. legal in void fns.

• ~~G0001: File-Scope Constant Needs a Constant Initializer~~  ✔ DONE
	• Emits: `initializer of a file-scope constant must be a constant expression`
	• Context: C only accepts constants at file scope; coralc accepts literals,
	  earlier file-scope `const`s (folded by value), casts, arithmetic on those
	  and function addresses. anything else (calls, runtime reads) used to leak
	  an "initializer element is not constant" gcc error; now it is caught with
	  a pointer at the initializer.

• ~~G0001: File-Scope Array Needs a Constant Initializer~~  ✔ DONE
	• Emits: `file-scope array initializer must be constant`
	• Context: `var a[2] = { f(), 2 };` at file scope. arrays cannot be
	  deferred to the runtime init pass, so the elements must fold.
	  (non-array `var` globals *can* be runtime-initialized: coralc emits an
	  `__attribute__((constructor))` pass before main.)

• ~~P0003: Tuple Type Spelling~~  ✔ DONE
	• Emits: `tuple types are written 'struct(A, B)'`
	• Context: `(A, B)` as a type. parens are not a tuple; the only spelling is
	  `struct(A, B)`. reported once per malformed type, parse continues.
